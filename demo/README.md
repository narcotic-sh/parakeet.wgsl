# parakeet.wgsl demo

This is the complete local demo for `parakeet.wgsl`. It consumes the library
through its public package boundary and mirrors the
[hosted demo](https://parakeet.narcotic.sh/).

## Run locally

From the repository root:

```bash
pnpm install
pnpm build
pnpm demo
```

The final command starts Vite and opens the demo in your browser. A
WebGPU-capable browser is required.
