parakeet.wgsl

Fast, accurate transcription in the browser, powered by WebGPU and WebAssembly.

This demo runs NVIDIA Parakeet TDT 0.6B v2 (English-only) entirely on-device. Audio never leaves the browser.

The model is downloaded when you transcribe for the first time, then cached for later visits.

Check out parakeet.wgsl on GitHub and npm for use in your own projects.
